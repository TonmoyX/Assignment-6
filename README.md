1. Project Name - DigiTools

2. A little Description -> This project is e-commerce type project. Here we can added product in cart and  also remove item from cart.

3. Technology that I use -> React.js, Tailwind CSS, DaisyUI, JavaScript (ES6+), React-Toastify (NPM Package), JSON (for product data) 

4. 3 Features about my project -> 1. product added to cart system 2. Remove single item from cart 3. Remove all item form cart by one click.
